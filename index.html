Attack Shark M87 / Xinmeng M87 — QMK & VIA Tri-Mode Firmware

A full-featured open-source QMK & VIA v3 firmware port for the Attack Shark M87 (also known as Xinmeng M87 / Xingmeng M87) mechanical keyboard powered by the SONiX SN32F248B MCU and WCH CH582F wireless coprocessor.

⬇ Download Latest Firmware (.bin & VIA .json) ⭐ View Source Code on GitHub

Key Highlights

  • Full Tri-Mode Wireless: Low-latency Wired USB (1000Hz NKRO), 2.4GHz RF, and Bluetooth 5.3 (3 profiles).
  • Full 4-Layer VIA v3 Support: Real-time key remapping, layers, and macros configuration on usevia.app.
  • Flash Wear-Leveling Protection: Live in-RAM RGB matrix adjustments with on-demand EEPROM commit (Fn + /).
  • Modular Custom RGB Engine: Smooth mode sweep transition, F8 startup ripple wave, soft-off expand/collapse animations, and inertia stepping for hue/brightness.
  • Power-Saving Soft-Off: Instant deep-sleep mode (Fn + `) shutting off all LEDs and suspending key scans until awakened.
  • Configurable Auto Shift: Integrated QMK Auto Shift disabled by default at boot, toggleable anytime via Fn + Left Shift.

Hardware Specifications

Feature Details
Commercial Models Attack Shark M87 / Xinmeng M87 (Xingmeng M87)
Layout Standard ANSI TKL 87-key (Tenkeyless)
Mounting Style Gasket Mount, Flex-cut PCB
Microcontroller (MCU) SONiX SN32F248BF / HFD2201KBA (ARM Cortex-M0 @ 48MHz, 64KB Flash, 8KB SRAM, LQFP-64)
Wireless Coprocessor WCH CH582F (BLE 5.3 & 2.4GHz RF, high-speed UART bridge)
Bootloader Mode Hardware Masked ROM ISP Bootloader (VID: 0x0C45, PID: 0x7040)
QMK User Mode VID: 0x0C45, PID: 0x8006
USB Polling Rate 1000Hz (1ms)

Pin Mapping

Key Switch Matrix (COL2ROW)

  • Rows (6): D11, D10, D9, D8, D7, D6
  • Cols (17): C12, C11, C10, C9, C8, C7, C6, C5, C4, C3, C2, C1, C0, C15, B15, B13, B12

RGB Matrix & Side Strips

  • Architecture: Common Anode (18-channel PWM Rows [R, B, G])
  • Row Pins (18): { A8, A9, A10, A11, A12, A13, A14, A15, B0, B1, B2, B3, B4, B7, B8, D3, B14, B10 }
  • Side Strips Anode Pins:
    • Pin 40 (B6): Left Strip (8 LEDs)
    • Pin 43 (B9): Right Strip (8 LEDs)
    • Pin 45 (B11): Logo Lightbar Strip (6 LEDs)

Bootloader Access

You can enter the Sonix ISP bootloader in two ways:

  • Software Shortcut: While the keyboard is connected, press Fn + Esc (Layer 1).
  • Hardware Bootmagic: Unplug the USB cable, hold down the Escape key, and plug the cable back in.

Flashing Firmware

Once the keyboard is in bootloader mode (VID: 0x0C45, PID: 0x7040), flash using the Sonix flasher utility:

./sonixflasher -v 0c45/7040 -f attackshark_m87_default.bin
